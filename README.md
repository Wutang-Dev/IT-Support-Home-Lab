# IT Support Home Lab – Practical 1st Line Simulations

## Overview

This repository documents a structured IT Support home lab built to simulate real-world 1st Line / Service Desk scenarios.

The purpose of this lab is to demonstrate hands-on ability with:

- Windows Server installation and configuration
- Active Directory Domain Services
- Domain Controller deployment
- User account management
- Password resets and account lockouts
- File share and NTFS permissions
- Microsoft 365 administration (planned)
- Structured troubleshooting methodology

This lab is designed to reflect practical tasks performed in entry-level IT Support roles.

---

## Lab Environment

- Hyper-V Virtualisation
- Windows Server 2022 (Domain Controller)
- Domain: IT.Support.Lab
- Static IP Configuration
- Active Directory & DNS
- Windows Client (Planned)
- Microsoft 365 Integration (Planned)

---

## Lab Structure

Each lab follows a consistent format:

- Scenario
- Environment
- Steps Performed
- Verification
- Outcome
- Example Ticket Documentation

---

## Objective

To demonstrate practical, hands-on IT Support capability through structured lab simulations aligned with real-world Service Desk responsibilities.
